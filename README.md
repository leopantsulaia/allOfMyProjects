# All Of My Projects

This is a starter Next.js + TypeScript portfolio site that scans sibling folders and presents each detected local project as a card.

## Run locally

1. Open `z:\Code\allOfMyProjects`
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the dev server:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:3000`

## What it does

- discovers local project folders next to `allOfMyProjects`
- filters folders that look like a web project
- displays cards with project name, folder path, and tags
